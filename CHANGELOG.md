# Changelog

## 0.1.2 desktop installer release candidate

Windows Setup adds Unsocial Network to the Start menu and Installed apps. One macOS package installs the native application in Applications on Apple Silicon and Intel. Ubuntu and Debian have a DEB installer with an app-menu shortcut. A portable TAR.GZ is available for other Linux distributions.

## 0.1.1 desktop release candidate

The Linux archive uses a space-free application directory and includes an AppArmor profile for Ubuntu's Chromium sandbox. The static download site offers versioned Windows, Linux, Apple Silicon and Intel Mac archives with SHA-256 checksums.

## 0.1.0 desktop release candidate

First implementation in the approved empty workspace. Adds invite-only rooms, TLS transport, live chat and presence, a self-hostable room service, desktop-hosted LAN rooms, durable chunk offsets and SHA-256 verification. Adds the retro desktop interface, encrypted session persistence when available, native download handling, portable release archives and integration tests.
