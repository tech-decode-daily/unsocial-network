# Room server API v1

Requests use the server origin in the invitation. Responses use JSON with the exact field capitalization below, except file content and WebSocket frames. Errors contain an `error` string. Bearer credentials travel in the Authorization header. All native clients omit browser Origin headers.

| Method and path | Authentication | Request and result |
| --- | --- | --- |
| GET /health | Public | Returns service name and protocol number |
| POST /rooms | Operator | `{Name, Display}` returns Room, Name, Member, Display, Token, Invite, Expires |
| POST /rooms/{room}/join | Invite in body | `{Invite, Display}` returns a new room-scoped session |
| GET /rooms/{room}/state | Member | Room, Name, Expires, Members, Files, Events, Cursor and More |
| GET /rooms/{room}/events?after=N | Member, WebSocket upgrade | Ordered event pages after N and updated member presence. A resuming client sends its last consumed sequence number |
| POST /rooms/{room}/chat | Member | `{Text, Key}`. Key is 32 hex characters generated by the client. Retries deduplicate within the member and room |
| POST /rooms/{room}/leave | Member | Revokes the membership and emits a departure event |
| POST /rooms/{room}/files | Member | `{Name, Mime, Size, Hash, Key}` returns ID, Name, Mime, Size, Hash, Offset, Sender, Member, Time and Ready |
| GET /rooms/{room}/files/{id} | Owner or member after publication | Returns current file metadata |
| PATCH /rooms/{room}/files/{id} | Owner | Contiguous bytes with Upload-Offset, Content-Length and Chunk-SHA256. Returns committed metadata |
| POST /rooms/{room}/files/{id}/verify | Owner | Publishes once size and entire hash match |
| DELETE /rooms/{room}/files/{id} | Owner | Cancels an unpublished upload |
| GET /rooms/{room}/files/{id}/content | Member | Published opaque bytes. Supports Range and 206 responses |

File and event timestamps are Unix milliseconds. Expires is Unix seconds. Sequences increase within one room. IDs and tokens are lowercase hexadecimal. File hashes are SHA-256 hex. HTTP 400 indicates invalid input, 403 a rejected credential, 404 an unavailable resource, 409 a conflict, 410 expiry, 422 an integrity failure, 429 throttling and 507 insufficient available storage. A swept expired room returns 404. Clients should handle network errors and 5xx responses independently for each transfer.
