# Download site design references

The page uses the desktop client's existing UN mark, cream surfaces, blue accent and green terminal globe. The terminal still life was generated for this site. The room directory image was captured from the working Windows client.

- Kokonut UI by Dorian Baffier, [Smooth Tab](https://github.com/kokonut-labs/kokonutui/blob/7e4bd770ca3f1ff4d93b9c1d0a61b11c3a51cbce/components/kokonutui/smooth-tab.tsx), MIT. The static selector adapts its sliding selection indicator and keyboard navigation using native buttons and CSS. The bundled Geist fonts retain their SIL Open Font License in the assets directory.
- LottieFiles, [Motion Design Skill](https://github.com/LottieFiles/motion-design-skill/tree/d77a9fc8cb371cab1ba5420df5bfd232cd14c9bb), MIT. The selection change combines a short eased indicator movement and a small panel entrance. Reduced motion follows the system preference.
- Damir Sokolovsky, [Unslop](https://github.com/heydamir/unslop/tree/620163eedb3529d9cd23a3994ed8d287d06f760d), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Its product-led visual direction informed the single hardware still life, the actual desktop preview and the page hierarchy.
